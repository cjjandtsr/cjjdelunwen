# 方法示意图文生图提示词 v1（2026-10-27）

适用：图1（方法总体框架）、图2（网络结构）、图3（两层决策与滚动执行）、图4(a)—(d)（场景类型示意）。这四张图不依赖实验数据，可用文生图生成。**图5—8及补充图S1、S2是结果图，必须用`make_figures_v2.py`从数据生成，不得使用文生图。**

## 0 使用须知

1. **模型选择**：优先用能较好渲染文字的模型（GPT-image / DALL·E 3、Ideogram、Midjourney v6以上、即梦/通义万相）。提示词用英文，模型对英文排版更稳定；图中标签也用英文，生成后如需中文再在PPT/Inkscape中替换。
2. **文字与箭头一定要人工核对**：文生图常出现拼写错误、多余或缺失的箭头、模块顺序错乱。每张图生成后按文末"核对清单"逐项检查，错误处在PPT/Inkscape/Figma中覆盖修正。也可以使用每张图提供的"无文字版"，只生成插画素材，文字和箭头全部手工添加，这种方式最稳妥。
3. **比例与分辨率**：图1、图2、图3为双栏横图，宽高比约2:1，生成后导出≥3000px宽；图4各小图为正方形。
4. **披露**：多数期刊要求说明AI生成图像。建议在图注或致谢中写："图1—图4中的示意插画借助生成式图像工具绘制，技术内容经作者核对。"投稿前查看目标期刊的具体规定。
5. **全文统一风格**（每段提示词都已包含）：白色背景；扁平矢量科研插图风格；浅灰圆角面板；柔和配色——BC/预训练相关用蓝色 `#3B6FB6`，后训练相关用橙色 `#E07B39`，观测与环境用浅绿 `#E8F1E4`，冻结模块用浅蓝灰 `#DCE3EE`；细线条，无阴影、无渐变、无三维光照特效。

## 图1中央Environment面板：局部感知视锥（方案一，2026-10-27）

### 1 这一块要表达什么

无人机在静态三维障碍环境中飞向目标，**只能通过前向深度相机看到视场内的局部障碍表面（点云），看不到全局地图**；策略据此生成一段轨迹，只执行前段（H4），其余为规划（H8），之后再重新规划。

### 2 画面规格

- 尺寸：单独生成，正方形1:1，≥2048×2048px；
- 视角：等距斜俯视，相机仰角约35—40°，从无人机后方偏右看向前方；
- 背景：纯白，无天空、无地平线；地面只占画面中下部。

### 3 元素、位置与含义

| 元素 | 画法与位置 | 含义（对应论文） |
|---|---|---|
| 地面 | 浅灰平面，极淡细网格，无纹理 | 静态环境地面 |
| U形陷阱 | 画面中上部，三块浅灰长方体箱体组成U形，开口朝向无人机 | 凹形障碍（U形陷阱场景） |
| 散布圆柱 | 4—6根不同粗细与高度的浅灰圆柱，分布在U形两侧与前方 | 障碍群 |
| 无人机 | 画面左下前景，蓝色四旋翼，机头有小型深度相机，机头朝向U形开口 | 本文无人机，前向深度相机 |
| 相机视锥 | 从相机伸出的浅蓝半透明四棱锥，水平张角约60°、略向下俯，长度覆盖到U形开口与内侧 | 深度相机视场（60°，下俯8°） |
| 点云 | **只在视锥内**、**只在朝向无人机的可见表面**（障碍正面、U形内壁、少量地面）上分布小圆点，颜色由低到高为蓝→黄绿；被遮挡的背面不画点 | 策略收到的局部点云 |
| 视锥外障碍 | 视锥外的障碍物整体淡化为很浅的半透明灰色，边缘细虚线 | 未被观测、策略不可见（无全局地图） |
| 目标 | U形封闭端后方的橙色小球 | 任务目标点，直连路线被U形阻挡 |
| H4已执行段 | 无人机身后到机头前一小段**青绿色实线**（较粗） | 已执行的H4前缀 |
| H8规划段 | 接在青绿实线之后的**蓝色虚线**，向U形外侧（右臂外侧）转弯，长度约到U形侧面中部，**不延伸到目标** | 当前规划窗口的未执行部分 |
| 后续路线 | 从蓝色虚线末端绕过U形外侧到目标的**极淡灰色点线** | 之后多次重规划才会形成的路线（示意） |

### 4 必须满足的关系

1. 点云只出现在视锥内的可见表面上；视锥外不出现任何点。
2. 视锥外的障碍明显淡化，与视锥内障碍形成对比。
3. 目标在U形后方，无人机与目标之间的直线被U形挡住。
4. 轨迹从无人机出发绕向U形外侧，不穿过任何障碍；实线短于虚线，虚线不到达目标。
5. 颜色与全图一致：点云蓝→黄绿（同Observation面板），执行段青绿、规划段蓝（同Receding面板图例），无人机蓝，目标橙。
6. 不出现建筑、混凝土纹理、植物、人物、文字。

本面板**单独生成一张完整图片**，不在原图上局部重绘。使用第5节（英文）或第6节（中文）提示词，在文生图工具中新建画布：
- 画布比例1:1（或宽:高=1:1.1），分辨率≥2048×2048；
- 场景居中，四周保留约8%的纯白留白，所有元素（含视锥、目标球）完整在画面内，不被裁切；
- 一次生成4张，选择最符合第4节关系的一张；不满足时只调整提示词重新生成，不做局部涂改；
- 导出PNG后，再作为素材放入整张图1的中央位置。
