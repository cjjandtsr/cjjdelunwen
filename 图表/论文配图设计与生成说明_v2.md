# 论文配图设计与生成说明 v2（2026-10-27）

适用稿件：[论文大稿_v2](../论文大稿_v2.md)。数据来源与用途：[论文实验数据清单_v1](../论文实验数据清单_v1.md)。
生成脚本：[make_figures_v2.py](make_figures_v2.py)，输出目录 `图表/v2/`。

原则：正文不展示个例轨迹图；结果图全部由脚本从原始数据计算，**不得用文生图生成或"美化"任何结果图**；文生图只可用于图1等方法示意图中的装饰性元素（无人机图标、场景渲染），且技术关系须与本文件一致、在图注或致谢中注明。

## 1 统一风格

| 项目 | 规范 |
|---|---|
| 尺寸 | 单栏8.5cm、双栏17cm；高度不超过22cm |
| 字体 | 中文无衬线（思源黑体/Noto Sans CJK SC/微软雅黑），数字与公式STIX；正文字号8pt，最小6pt（缩印后仍≥6pt），面板标签(a)(b)9pt粗体左上 |
| 策略色 | BC策略 `#3B6FB6`（蓝）；后训练策略 `#E07B39`（橙） |
| 结局色 | 到达 `#2E9E5B`（绿）；碰撞 `#C8423B`（红）；超时 `#9A9A9A`（灰） |
| 方法图配色 | 观测/环境浅绿 `#E8F1E4`；冻结模块浅蓝灰 `#DCE3EE`；后训练模块浅橙 `#FBF0E6`；LoRA层橙色虚线框；普通模块浅灰 `#F3F4F6`，边框 `#5B6573` |
| 线与箭头 | 数据流实线；梯度/参数更新虚线（橙=后训练，蓝=预训练）；观测反馈弯箭头 |
| 坐标轴 | 去上/右边框；浅灰网格`#E5E5E5`；柱顶标数值（1位小数） |
| 输出 | PDF矢量 + PNG 600dpi |
| 图注 | 三句以内：表达什么→元素含义→样本来源；不写免责说明 |

## 2 运行方式

```bash
pip install numpy matplotlib          # 需要能显示中文的字体，如 Noto Sans CJK SC
python 图表/make_figures_v2.py --data-only   # 先核对数值（应与正文表4—7一致）
python 图表/make_figures_v2.py               # 生成全部
python 图表/make_figures_v2.py --only 5 7     # 只生成部分
```

`--data-only`已在无绘图库环境中核对通过：原任务密集受阻6.4%→12.0%、U形受阻15.6%→28.9%、新任务密集7.8%→28.9%等，全部与正文一致。中文显示为方框时，安装中文字体并删除matplotlib字体缓存后重跑。

### 图1 方法总体框架

**布局（双栏，约17×9cm）：** 上半实线框"导航闭环"，从左到右五块：①局部点云插图＋"状态、目标"标签（浅绿）→②PointNet编码器(128/帧)与状态MLP(64/帧)，标"冻结"（浅蓝灰）→③条件向量576维＋扩散时间步→FiLM→条件一维U-Net，DDIM 10步→④轨迹H16(16×11)→规划窗口H8→执行前缀H4(4×0.3s)→⑤运动学仿真环境（碰撞/到达判定、合成新点云，浅绿）；⑤底部弯箭头回到①，标"每0.3s更新观测，每1.2s重新规划"。下半虚线框"两阶段训练（评价时移除）"：左"①示范预训练：EGO示范988回合，L_BC+λL_geo，更新完整策略"，蓝色虚线指向编码器；右"②交互后训练（DPPO）"一行：奖励r_t→价值网络V(c,β)→GAE优势/去噪折扣→PPO截断代理（橙边框，"仅更新LoRA"），橙色虚线箭头指向U-Net；价值网络下方"价值回归L_V"，橙色虚线指回价值网络；环境到奖励一条点线。

### 图2 网络结构

**内容：** 左列输入（点云3帧×4096×3、状态3帧×9）→多阶段PointNet（逐点Conv1d 3→128，4阶段"局部⊕全局最大池化"，512→128，最大池化，128/帧）与状态MLP（9→64→64）【冻结】→拼接192/帧×3=576维条件；扩散步k→正弦编码→MLP→128；条件与时间步拼接704维→FiLM(γ,β)作用于每个残差块→条件一维U-Net（256@16→512@8→1024@4中间层→512@8→256@16，卷积核5，GroupNorm 8，Mish，跳跃连接）→输出16×11。U-Net各级用橙色虚线框表示加入LoRA（14线性层+33卷积层，秩8，可训练102万参数）。

**交给绘图智能体的提示词：**

> 绘制扩散策略网络结构图（双栏17cm×7cm）。运行`python 图表/make_figures_v2.py --only 2`得到骨架，可精修。从左到右：输入块（点云3×4096×3；状态3×9，浅绿）→PointNet编码器（多阶段，输出128/帧）与状态MLP（9→64→64），两者浅蓝灰并标"冻结"→拼接得576维条件c_t；下方扩散步k→正弦编码→MLP→128；二者拼接704维→FiLM块（输出γ、β，作用于每个残差块）→U-Net五个柱形块高度先降后升：256@16、512@8、1024@4（中间层）、512@8、256@16，块间实线，下采样侧到上采样侧画两条点线跳跃连接，五块都用橙色虚线边框表示LoRA层→输出16×11。底部注："卷积核5、GroupNorm 8、Mish；橙色虚线为后训练LoRA层（14线性+33卷积，秩8）"。数字不得改动。
