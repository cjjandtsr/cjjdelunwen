# 论文图表专项审稿：图2、图3及两组负向案例

现在有了图片本体，可以对图中的实际内容进行审查，而不再仅依据图注推断。

总体判断：这四组图采用真实轨迹和配对结果，具有明确的研究价值，但仍有一些“数据真实、图也画对了，却没有把研究发现充分表达出来”的问题。

其中，图2需要突出成功与失败的交换关系；图3需要让读者更容易识别几何通过、重新接近和最终入球之间的区别；两组负向案例则不应只作为证明“存在能力流失”的补充材料，还应帮助界定正向结论的适用范围。

我会按照三个标准审查每幅图：

1. 可读性： 不看正文，能否判断图中的轨迹、标记、颜色和数值代表什么？
2. 证据价值： 图中每个内容是否回答了一个有研究意义的问题？
3. 图文一致性： 论文文字是否准确概括图中的现象，是否遗漏反例或作出超出图片证据的推断？

本轮图1仍未提供，因此以下视觉审查涵盖实际上传的图2、图3及补充图S1、S2。

## 一、图2：确实展示了“成功交换”，但视觉重点还不够准确

审查对象：figure_02_paired_results.pdf，第1页，(a)、(b)两个子图。

### 图2(a)：四类配对结果

证据价值高

这张图最容易让读者理解的是：双方共同成功57次，只有RL成功68次，只有BC成功59次，共同失败236次。

但实际看图后，我发现三个问题。

第一，最醒目的柱子是236次共同失败，而不是68次新增与59次流失。

236是最大的计数，所以柱子最高。这在数学上正确，却不符合这张图最重要的研究任务。论文希望解释的是为何净增9次背后存在大量成功交换，而不是强调共同失败数量最大。

可以保留236，但建议在68和59之间直接标注：

Net change = +9 (68 gained − 59 lost)

使读者无需心算就能理解研究发现。

第二，柱子的颜色没有形成统一语义。

图2(a)使用蓝色表示共同成功、橙红色表示RL独有成功、灰色表示BC独有成功或双方失败；图2(b)却使用蓝色表示直连未受阻、橙红色表示直连受阻。

同一幅组合图中，蓝色和橙红色突然改变含义，容易造成误读。

建议上图以中性颜色为主，仅突出新增与流失，或明确分开两种配色体系。

第三，这个子图无法展示失败类别的转换。

这不是绘图错误，而是信息选择问题。你已经有完整的三类终点转换数据，因此需要明确为什么主图要使用二元成功/失败分类。

我的判断是：如果图2(a)的唯一目的是揭示新增与流失，现有四柱图可以保留；但若还希望解释碰撞增加的来源，四柱图就不够。

不要让一幅图承担它没有显示的结论。

### 图2(b)：84项任务的变化

证据价值很高

这张图的优点是保留了全部84项任务，因此读者可以看到正负变化并存，而不只是三个正向任务。

图中task20、30、32已经通过编号突出，task75也得到标注。方向是对的。

但真实图片显示，红色受阻任务的主要变化被大量蓝色柱子包围，整体很难迅速判断全部受阻变化究竟集中在哪里。

另外，49项净变化为零的任务基本压在零基线上，读者几乎无法区分这些任务和绘图留白。

我建议图2(b)至少回答以下问题：

| 审稿问题                  | 目前图片能否直接回答？         |
| --------------------- | ------------------- |
| 哪些受阻任务出现正向变化？         | 可以，20、30、32已标记      |
| 哪些受阻任务出现负向变化？         | 不充分，仅75突出；17、47需要查找 |
| 改善是否遍布全部84任务？         | 可以看出并非遍布            |
| 49项净零变化中是否发生过成功与失败抵消？ | 不能，需要额外配对统计         |
| 哪些任务代表纯粹的直连未受阻能力变化？   | 有颜色分类，但没有清晰的行为说明    |

我不建议简单删除49项零变化任务，因为它们能说明整体变化的稀疏程度。

更好的做法是考虑将任务按受阻/未受阻分组排列，组内再按照到达计数差值排序。这样既保留完整性，又让主要研究发现更容易识别。

图2的结论：保留，但需要调整视觉强调方向。它不应只是两幅统计图，而应该清楚回答“净增来自哪里，代价发生在哪里，受阻增益为何集中于少数任务”。

## 二、图3：研究价值最高，实际视觉表达仍有明显问题

审查对象：figure_03_executed_trajectories.pdf，第1页，三任务×三行子图。

图3的核心价值是它使用了真实已执行轨迹，且每个任务都保留BC与DPPO的全部五次重复。

这是一个正确的证据选择。

但实际看图后，最明显的问题是：9个面板同时呈现，空间被平均分配，而三个任务的重要性和研究目的并不相同。

### Task 30：最有价值的是“先外绕，再重新接近”

这组图非常直观。BC五次路线从起点向左侧延伸后均未完成；RL五次先有类似向外运动，随后明显沿障碍群外围向目标方向延伸，四次成功。

这比单独的4/5成功率有解释力，因为读者看得见空间行为发生了什么变化。

但我发现：绿色的失败重复与其他四条成功路线在很长一段上重合，到目标附近才出现较明显差异。

这其实是比单纯4/5成功更有价值的观察。

建议在task30的目标附近添加局部放大区，着重显示成功重复与失败重复在末端的分化。尤其是重复3最近距离0.514m，与到达阈值0.5m差别极小，在当前25m纵坐标尺度的距离图中几乎不可能直接识别。

这组图应突出两个阶段：前半段的外围绕行行为，以及末端目标完成的差别。

### Task 20：这组图能够非常清楚地证明一个局部现象

Task20是我认为实际绘图与研究问题匹配度最高的一列。

BC五次主要停留在左上方区域并超时；RL五次则沿左侧绕过障碍群，继续进入目标附近。图中菱形几何通过标记与下方目标距离曲线相互对应。

更重要的是，RL在目标附近出现明显的大范围回环，两次最终到达，三次超时。

这使该案例非常适合回答：

> 已经通过初始障碍，是否意味着能够继续稳定完成目标导航？

从目前图片和正文看，答案是否定的。

但我建议进一步强化时间顺序。图中菱形标记对应的约24秒几何通过事件，和后续近目标回环之间存在一段很长的执行过程。可以用细竖线或标注将距离曲线中的“通过障碍”与“近目标回环”区分开。

注意这里不应把回环直接解释为某个reward项造成，也不应把它等同于严格的“恢复失败”。它只是一个需要进一步解释的实际执行现象。

### Task 32：这列的轨迹图有价值，距离曲线的独立价值较弱

Task32显示了明显的空间路线分化。

BC轨迹没有完成任务，部分停在障碍附近；RL中三条路线向外围展开并到达目标，两条较短轨迹则在途中碰撞。

这列最重要的不是“3/5成功”，而是轨迹能否形成完整外围进路与最终安全结局之间的对应关系。

因此，顶部两张轨迹图有明确价值。

但下方目标距离曲线，目前主要重复了成功轨迹靠近目标、失败轨迹中途终止这一现象。正文没有充分利用这些曲线去说明一个轨迹图无法回答的问题。

我的建议是先问作者：

> Task32的距离曲线，是否揭示了碰撞之前独特的目标推进行为？

如果没有，考虑将该曲线放入补充材料，而不是机械地保持三列三行对称。

### 图3共有的视觉问题

我实际看到了以下不足：

- 五次重复的轨迹经常高度重合。 特别是task20的前半段，不容易确认五次重复是否全部绘出。建议使用局部放大或透明度辅助，而不是依赖五种颜色。
- 图例过度依赖读者记忆。 颜色区分重复、实线虚线区分策略、不同符号区分事件。读者需要反复在图底查找含义。
- 二维障碍投影可能产生误导。 某些轨迹与灰色障碍区域视觉重叠，但这不能作为三维碰撞或安全通过的判据。最好加入高度剖面或局部三维视角。
- 所有小图字号偏小。 当前图片已经采用较大的整体画布；若再缩小至期刊双栏宽度，坐标和事件符号会更加难读。

图3不一定需要增加新内容，反而应考虑减少非关键面板，把空间留给真正需要放大才能理解的行为。

## 三、补充图S1：Task75能力流失案例

审查对象：figure_S1_loss_case.pdf，第1页。

这张图的研究目的相对清楚：展示一个BC能够持续成功、而RL全部失败的受阻任务。

从实际图片看，BC五次轨迹高度一致，最终到达目标；RL五次则在障碍附近出现局部反复运动，并在未能继续向目标推进的情况下碰撞终止。下方距离曲线也清楚显示，BC最终接近目标，RL则停留在距离目标约16—19m的范围。

这幅图确实证明了当前评价中存在明显的局部成功流失。

但是，它有两个很重要的限制。

首先，BC路线在二维投影中与部分灰色障碍矩形发生视觉交叠。这不等于三维碰撞，但如果没有说明高度关系，审稿人可能质疑：为什么图中看似穿过障碍的轨迹被判定为安全？

其次，该任务存在已知的物理几何与合成点云表示不一致问题。图中呈现的轨迹本身不能识别这一问题，更无法证明全部失败都由强化学习更新导致。

因此，我建议在图注中明确写出该任务的已知观测限制，并在需要时附局部高度视图。否则这幅图容易被理解为未经混杂因素约束的算法退化证据。

另一个值得考虑的问题是图形尺寸：目前S1采用很高的纵向画布，实际轨迹占比不大。作为补充图可以接受，但仍可缩小空白，适当放大局部障碍区域。

我的判断：S1应该保留，不过它适合作为带明确环境限制的失败案例，而不是主要的退化机制证据。

## 四、补充图S2：Task17和Task47更值得深入利用

审查对象：figure_S2_other_losses.pdf，第1页。

这组补充图的意义不应只是告诉读者“除了task75还有其他流失”。

实际图片显示，两项任务的失败表现并不相同。

### Task17：相似初始路线，结局出现分化

Task17中，BC和RL在早期的实际路线相当接近，RL的轨迹最终集中终止于障碍附近，而BC至少有一次继续到达目标区域。

这说明即使总体路线方向相似，后续局部执行仍可能产生不同终点。

但仅从二维图不能确定究竟是哪个动作、哪一段三维路径或哪种观测差异导致了碰撞。

它最值得回答的问题是：

两种策略从相同初始条件出发，在什么位置第一次出现具有安全后果的轨迹差异？

这个问题可以借助现有原始轨迹、碰撞位置和障碍几何进一步分析，而不必重新训练。

### Task47：已经接近目标，也可能丢失原成功结果

Task47的RL轨迹有两种很明显的失败形态：部分重复较早碰撞；另一些重复到达目标附近，却出现大幅度局部回环或未完成现象。

它与task20形成了很有意思的对照：

| 案例     | 观察到的行为                    | 对论文意味着什么           |
| ------ | ------------------------- | ------------------ |
| task20 | RL绕过障碍后接近目标，但只有2/5成功      | 新增绕障行为不保证最终完成      |
| task47 | RL部分重复已接近目标，仍未保持BC原有的全部成功 | 目标附近完成问题也可能伴随原成功流失 |

我认为task47具有比当前正文赋予它的更高的分析价值。

它可以帮助全文从“RL新增了绕障成功，但有些没到达”，提升到一个更完整的研究观察：后训练改变了到达目标的过程，既可能创造原先没有的成功，也可能使原有成功在局部碰撞或目标附近的后续执行中流失。

不过，这两个任务都是事后观察案例，不能仅凭图片证明存在同一个内部机制。

我建议保留S2，并在4.3结尾用一两句话主动指向task17和47的不同流失过程，而不是只告诉读者它们也发生了成功流失。

## 六、综合审稿结论与修改优先级

现在真正看到图后，我对这组图的评价比此前更积极。

图2能够说明总体净增掩盖大量成功交换。图3确实展示了三种不同的受阻执行表现。补充图S1、S2也提供了必要的反向证据。 它们不是为了凑图表数量而存在。

但是，目前仍需要三类修改。

优先级一：确保图片中的研究发现一眼可见。 图2突出68次新增与59次流失的关系；图3突出几何通过、重新接近与最终入球的区别，而不是要求读者从大量重叠曲线中自行发现。

优先级二：确保每个子图增加独立证据。 task30的近目标放大、task20的通过后过程、task32的距离曲线取舍，以及task47的反例价值，都应该以“是否回答了额外问题”为标准决定。

优先级三：控制图像与文字结论的距离。 二维投影不能代替三维碰撞核查，局部回环不能直接证明恢复机制，正向与负向案例也不能独立证明DPPO某个组件的因果效果。

我尤其建议最终正文围绕以下逻辑组织图表：

图2：后训练改变了哪些结果？

图3：新增到达究竟通过什么实际执行行为实现？

补充图S1/S2：哪些原有行为同时流失，这些流失表现与正向行为有什么联系？

这样四组图就形成了一条连续证据链，而不是各自展示若干条轨迹。

最终判断：当前图表基础值得保留，暂不需要大规模新增实验；最值得投入的是重新设计视觉重点，并利用已有原始轨迹回答少数关键问题。 特别是task20、30、47的目标附近行为，可能成为本文最有解释价值的结果之一，但必须保持对实际证据和机制归因的严格区分。
