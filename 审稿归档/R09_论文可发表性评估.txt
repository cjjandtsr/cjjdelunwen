# 论文可发表性评估：应该继续，还是停止？

结论：有条件地继续

我重新审视了最新《论文大稿(6).md》的研究定位、方法、P2实验结果、图表论证以及尚未完成的P3计划，并结合此前讨论的 Enhancing、DPPO、X-NavDP 等研究进行判断。

我的结论是：目前已经具备一篇学术论文的基本框架和有价值的实证材料，但尚未具备足够扎实的期刊论文核心贡献。如果只是继续补写P3、讨论、引言和结论，最终很可能成为一篇写作规范、数据丰富的工程实验报告。

不过，我不建议现在停止。现有数据揭示了一些值得研究的现象，只是还需要将它们从“实验中发生了什么”提升为“能够产生什么可验证、可迁移的科学认识”。

## 一、当前论文究竟处于什么水平？

| 评价维度   | 当前判断      | 主要原因                          |
| ------ | --------- | ----------------------------- |
| 研究问题   | 基本成立      | BC后训练的局部收益与原能力流失值得研究          |
| 技术方法   | 完整，但原创性有限 | 主要继承扩散策略、DPPO和LoRA，没有提出新的优化算法 |
| 实验规范   | 较好        | 配对种子、连续轨迹、终止判定和评价边界明确         |
| 数据价值   | 有实质价值     | 结果转换、行为集中性及实际执行过程揭示了非平凡现象     |
| 科学解释深度 | 仍然不足      | 已观察到行为差异，但尚未充分解释它们为何发生        |
| 结果可靠性  | 主要短板      | 单个事后选定检查点、开发集评价、缺少独立验证        |
| 图文组织   | 已接近期刊写法   | 每个主要图表已有明确用途，仍需最终修图和全篇整合      |
| 可推广性   | 较弱        | 未见几何、不同训练种子及动力学条件下的结论尚不明确     |

因此，现在的问题已经不主要是写作，而是研究证据能否支撑一项值得发表的科学贡献。

## 二、这篇论文已经具备哪些真正的研究价值？

我认为有三项值得继续挖掘。

### 1. 后训练不是简单地在BC能力上增加成功案例

这是目前最扎实的发现之一。

新增成功

# 68

原成功流失

# 59

净增成功

# +9

这说明扩散策略后训练可能产生显著的任务结果重新分布，而不是单纯提高已有策略的表现。

但需要注意：这仍是特定检查点、特定评价协议下的观察，不能直接推断所有DPPO训练都会如此。

如果能够进一步解释这种成功交换与后训练过程的关系，它就可能成为具有研究价值的发现。

### 2. 复杂绕障行为与最终任务完成并不等价

这是目前最有潜力成为论文核心的发现。

Task20中，RL五次重复都满足定义明确的初始阻挡物几何通过条件，但只有两次最终到达。

Task30中，五次重复都形成外围绕行并重新接近目标，但仍有一次在最近达到0.514m后超时。

这些观察共同说明：

策略能够形成可行的空间绕行，并不意味着它能在后续滚动执行中稳定完成目标。

这比仅声称“RL学会了绕障”更值得研究。

它与扩散轨迹规划的滚动执行特征直接相关，而且可以自然引出P3的同初态比较。

不过，当前仍不能确定失败源于奖励、信用分配、目标条件利用，还是重规划后的动作分布变化。

### 3. 同一个后训练策略在不同任务中的行为变化高度不均匀

受阻任务的9次新增成功全部来自三个任务，成功流失则出现在其他任务。

这说明总体成功率不足以反映策略的局部行为变化。

但仅证明“效果不均匀”还不够，因为几乎所有学习算法都可能存在任务异质性。

更重要的科学问题是：

哪些可观察的任务条件或状态特征，能够解释这种不均匀变化？

如果能发现具有重复性的规律，并通过独立数据验证，就有可能形成比单纯案例分析更强的贡献。

## 三、为什么目前仍然有变成工程报告的风险？

### 风险一：全文目前主要回答“发生了什么”，没有充分回答“为什么”

当前论文的论证链是：

BC与RL整体结果不同

差异集中于特定任务

轨迹显示绕行和目标接近行为不同

同初态下是否仍有策略差异

待P3

差异与哪些可检验因素有关

尚缺证据

结论能否超出所选开发任务

尚缺证据

前三个层次已经比较扎实，但它们更接近严谨的描述性分析。

期刊论文并不一定要求证明完整的因果机制，描述性实证研究也可以发表。但它通常需要有足够重要、可复核且超出个别案例的发现。

目前本文尚未证明这一点。

### 风险二：缺少独立验证，比缺少更多漂亮的图更严重

当前评价的21个世界与训练几何没有隔离，所选u32也在查看开发结果后确定。正文已经诚实披露了这些问题。

论文大稿.md



但披露局限不等于解决局限。

假如P3继续从同一开发任务中的优秀RL轨迹提取状态，再证明RL在这些状态下表现较好，那么这个实验虽然可能帮助理解局部行为，却未必能解决事后选择带来的偏差。

因此，P3和独立验证承担不同职责，不能相互替代。

P3主要回答局部状态下两种策略的行为差异；独立评价则回答这种发现是否对未参与选择的任务仍然有意义。

### 风险三：目前还没有特别有力的总体正向结果

在420个开发评价条件中：

- 安全到达从116增至125；
- 碰撞从131增至158；
- 初始直连受阻条件的到达仅从18增至20。

这不是一个可以自然支撑“提出更优无人机导航算法”的结果。

如果论文以“DPPO提升无人机复杂环境规划性能”为主要贡献，审稿人很容易要求更加充分的成功率、安全性、多训练种子和消融证据。

但如果定位为扩散策略强化学习后训练的局部行为变化及其局限性的实证研究，当前证据就更贴近研究目标。

关键在于：该研究必须形成超出特定实现的认识，而不只是记录这个项目的得失。

## 四、与 Enhancing 等论文相比，主要差距在哪里？

你此前提供的 Enhancing UAV Path Planning with Diffusion Models and Group Relative Policy Optimization 将研究贡献与多方面实验对应起来：成功率、路径效率、安全性、训练稳定性、组件消融和计算性能。

它不只是列出这些指标，而是试图使用它们分别回答不同的研究主张。

X-NavDP 和 Beyond Imitation 等工作也通过不同环境、轨迹分析及方法对照，尝试说明改进行为是否具有更广泛的适用性。

相比之下，当前论文有一个特点：

轨迹级行为分析比普通的成功率对比更细致，但对行为改善的可靠性和成因，证据不如这些以性能提升或方法创新为主的研究充分。

所以我不建议为了模仿它们而增加大量无关指标。当前更合理的发表路线不是与这些论文竞争“谁的算法性能最高”，而是提供一个扎实的、问题驱动的经验研究。

也就是说，本文最有希望回答的是：

> 在点云条件扩散轨迹策略的滚动导航中，强化学习后训练为什么可能产生局部绕障收益，却未必保留原有成功行为或保证最终目标完成？

目前已经能提出这个问题，却还不能完整回答其中的“为什么”。

## 五、下一步究竟应该怎么做？

我建议继续，但设置明确的研究决策点。

| 下一步             | 目的                                        | 优先级                 |
| --------------- | ----------------------------------------- | ------------------- |
| 完成P3同初态比较       | 区分原始轨迹中状态分化与相同状态下策略选择的差别；同时纳入正向、负向和BC保持状态 | 必须                  |
| 增加独立评价          | 使用不参与选模型和选案例的新任务或新几何，检验结论是否仍成立            | 必须，若目标是具备说服力的期刊实证论文 |
| 检查训练重复性         | 尽可能利用其他训练种子或独立运行，判断现象是否只属于u32一次训练         | 很高                  |
| 进行有限机制验证        | 根据P3发现，针对最关键的一个解释设计受控对照，而不是大量消融           | 视P3结果               |
| 最后完成引言、讨论、摘要和结论 | 将已经证实的结果组织成清晰的科学贡献                        | 证据收口后               |

我特别不建议现在继续进行无止境的P1/P2文字打磨。最新稿的行文和图表结构已经足以支撑下一阶段研究，剩余文字问题可以等结果完整后统一解决。

### 建议设置的继续/停止条件

继续按期刊论文推进

如果P3发现具有一致性的局部状态差异，并且独立评价或跨训练运行能够支持至少一项重要发现，即便总体成功率没有显著提高，也可以继续按照局部行为与能力权衡的实证论文组织。

重新收窄论文定位

如果P3只确认少数开发案例的差异，独立评价没有重复出现相似规律，但能够清楚识别一个具有可检验价值的失败模式，可以考虑针对该失败模式进行一次有限的受控实验，定位为方法局限或失败分析论文。

停止以完整期刊论文为目标扩写

如果新证据仍只说明“某次训练的某些任务成功、另一些失败”，无法建立可重复的行为规律、独立评价证据或有意义的机制解释，则应将现有材料收口为技术报告、实验研究记录或规模较小的案例研究，而不应继续投入大量论文包装工作。

## 六、我对发表前景的判断

| 投稿定位                  | 当前前景              |
| --------------------- | ----------------- |
| 强调新算法与普遍性能提升的高水平机器人期刊 | 目前证据明显不足          |
| 机器人学习、无人机规划方向的应用型期刊   | 有可能，但需要补足关键独立证据   |
| 以后训练行为权衡、失败模式为主题的实证研究 | 相对最合适，但需要可重复的研究发现 |
| 工程实现或实验技术报告           | 现有材料已经较为充分        |

这里的“有可能”不是录用概率预测；不同期刊对创新性、仿真验证、代码和实验规模的要求可能差异很大。

## 七、最终建议

我建议继续完成P3，但将P3视为一次决定论文是否继续投入的科学验证，而不是已经确定会完成期刊论文的写作阶段。

当前最需要避免的是两种极端：一是因为没有显著的总体性能提升，就放弃已经获得的完整行为证据；二是因为轨迹案例很有意思，就认为补齐引言和讨论后自然能够投稿。

现在已经有一个值得继续探索的研究问题，也具备较好的原始轨迹证据基础。但真正决定这篇文章是学术论文还是工程报告的，不是章节是否完整，也不是图表是否精美，而是最终能否形成一个经过充分检验、对其他研究者有参考价值的结论。

我希望下一阶段只围绕一个关键问题作决策：

我们最终准备证明的是“DPPO能让这个无人机策略在某些受阻任务上获得新成功”，还是“扩散策略在滚动规划后训练中存在具有普遍研究价值的局部能力收益与保持冲突”？

前者目前已经有描述性证据，但作为完整期刊论文贡献偏弱；后者更有学术价值，但需要更强的验证。

我的判断是：继续研究，暂缓扩大写作投入；完成P3和必要的独立验证后，再决定是否正式收口为期刊论文。
