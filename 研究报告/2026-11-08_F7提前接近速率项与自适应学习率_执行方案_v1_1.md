## 一、为什么做这两项

### 1.1 每次更新几乎没有移动策略【事实】
F3 的两次运行 P9、P11 在 u129—u192 的训练记录（附录 B 脚本）显示：
- 每轮 approx KL 均值的中位数为 7.3e-7（P9）和 8.5e-7（P11），最大 7.9e-6。
- clip_fraction 每轮均值的中位数为 0（P9）和 1e-5（P11）；64 轮中分别有 42 轮和 32 轮恰为 0；单次提交最大 0.5%。
- 概率比均值的最小值为 0.999，即每次更新对数概率改变不到 1e-3。PPO 截断（按去噪步 0.001→0.1）几乎从不起作用。
- 学习率只有 1.5e-5→1.25e-5（LoRA）。
- 每轮耗时：采集约 330 s，更新约 34 s，采集占 91%。

【文献事实】DPPO 论文把截断系数调到 clipfrac 约 10%—20%；腿式机器人和 Isaac Lab 常用的 PPO 实现（rsl_rl）按目标 KL 自适应调整学习率；LoRA 的最优学习率约为全参数微调的 10 倍（Thinking Machines，LLM 上的结论）。DPPO 仓库也说明提高 actor 学习率能提高样本效率。

【推断】我们的更新幅度比常规设置低约两到三个数量级，限制来自学习率，而不是截断或数据。更新只占 9% 的时间，所以调大更新幅度几乎不增加耗时。

### 1.2 现有风险项只在很近处起作用【事实】
- reward v2 的风险项对执行段（第 1—4 段）和计划尾段（第 5—8 段，权重按 2^(−(j−4)/4) 衰减）都打分，但只在净空 < 0.45 m 时非零（二次屏障，0.10 m 处饱和），且每决策取各段最大值，幅度 ≤ 1。
- 所以"对 8 个预测点都打分"在 v2 中已经存在；缺的是距离范围和对接近速度的区分。
- F5 用过的 v3 接近项 `risk_close`：接近距离 × ((1.2−c)/1.1)² 屏障，系数 4。按实测中位速度 0.63 m/s 正面接近计算，决策起点净空 2.0 m 时为 0，1.6 m 时为 −0.097；v2 风险项在 1.3 m 时仍为 0（附录 C2）。F5 同时改了任务库，结果不能单独归因于该项。

【项目事实】碰撞诊断：P6 在 dev420 的 138 次碰撞中，被撞障碍在碰撞前 2—3 个决策已在视野内（85%—90%），但 8 步规划到前 1 个决策才穿过它（77%）。dev420 原迹实测（附录 C1）：P6 分段速度中位数 0.63 m/s（p90 0.91），每决策前进 0.75 m；BC 为 0.34 m/s。因此被撞障碍约在 1.5—2.3 m 外已经看见。

### 1.3 采用的做法【文献事实】
- **控制屏障函数（CBF）型安全奖励：** r = clip(ḃ + γ b, −c, 0)，b 为净空减安全裕度。它惩罚"相对剩余距离而言接近得太快"，因此在安全区域内就提前给信号；切向掠过和远离不受罚；减速或侧偏都能消除惩罚。arXiv 2602.08653 用此项把 3、5 m/s 下的成功率从 62.3%、67.8% 提到 84.5%、94.0%；同类软 CBF 惩罚已在本项目参考文献中（Liu 2026，GRPO-MDP）。按接近速度加权的碰撞项也是常用设计（arXiv 2407.10648、2509.08177）。
- **按更新幅度自适应调整学习率：** rsl_rl 等实现的标准做法。本方案用 clip_fraction 作指标，因为它的定义不依赖 KL 的计算口径。

## 三、reward v5：提前接近速率项（新增项名 `approach_cbf`）

### 3.1 定义
对每个决策实际执行的路径（与 v2、v3 相同，碰撞时取截断到首次接触的路径）的点 p_0…p_n，及各段实际时长 Δt_k：
- c_k = 点 p_k 到最近障碍的净空，用 v2 已有的 `_obstacle_clearances(np.stack((p, p)), obstacles)`（与 v3 `closing_cost` 相同的调用方式；只含障碍，不含地面，地面已有 v2 的地面风险项）。
- b_k = c_k − d_safe。
- v_k = −[(b_{k+1} − b_k)/Δt_k + γ (b_k + b_{k+1})/2]。
- raw = −w × Σ_k Δt_k × clip(v_k, 0, v_max)。
- 回合预算：`approach_cbf` = max(raw, −(B − used))，used 为本回合此前各决策该项绝对值之和，回合开始时清零。
- 总 reward = v2 总和 + `approach_cbf`；v2 五项及系数完全不变。invalid_state 决策该项记 0。

| 参数 | 值 | 含义 |
|---|---|---|
| d_safe | 0.30 m | 安全裕度（碰撞判定 0.10 m 之外再留 0.20 m） |
| γ | 1/3 s⁻¹ | 时间余量 3 s（约 2.5 个决策）：按当前速度 3 s 内会贴近即开始扣分 |
| w | 2.0 | 系数 |
| v_max | 2.0 m/s | 单段违反量上限 |
| B | 4.0 | 每回合上限 |

### 3.2 数值性质（附录 A，可手算）
- 0.45 m/s 正面接近：起点净空 1.6 m 时 −0.256，1.3 m 时 −0.496；2.5 m 时 0。同一情形下 v3 分别为 −0.009、−0.141。
- 切向掠过（净空不变，0.5 m）、远离障碍、减速到 0.10 m/s（起点 1.0 m）都为 0。
- 单决策 |raw| ≤ w × 1.2 × v_max = 4.8；每回合累计 ≤ 4。
- **成功与超时的次序仍有保证：** R1 设计 v1.4 §1.4 推导的 G_success − G_timeout ≥ 5.5108，减去 space 项 1、本项上限 4，下界为 0.5108 > 0。

### 3.3 开训前的标定检查（预先写定，Claude 计算）
- 数据：P6 第二阶段训练采集的逐决策执行路径与训练世界几何（训练域，非评价原迹）。Codex 只读导出，Claude 计算。
- 规则：按 3.1 计算每回合的 `approach_cbf` 和。若 **到达回合的中位数 < −2.0**，或 **达到回合上限 B 的回合占全部回合 > 30%**，则 w 改为 1.0（唯一备选，事先写定），其余不变；否则用 w = 2.0。结果写入核对单后开训。

### 3.4 随速度缩放
开始扣分的净空约为 d_safe + v/γ = 0.3 + 3v：0.63 m/s 时 2.2 m，1 m/s 时 3.3 m，2 m/s 时 6.3 m（附录 C2）。预警距离随速度自动变长，固定半径的距离项做不到这一点。以后速度提高时，每回合上限 B 需要相应放大（2 m/s 时单决策即可达 4），本轮不改。

## 四、自适应学习率（只作用于 F7 臂的 actor）
- 倍率初值 m = 10（第 1.1 节显示截断远未起作用，所以直接放大一个数量级）。
- 每个外层更新结束后，读取该轮 20 次提交的 `clip_fraction` 均值 c：c < 0.05 → m × 1.5；c > 0.15 → m ÷ 1.5；其余不变。m 限制在 [1, 50]。下一轮 actor 学习率 = 1e-5 × m。
- 评论家学习率、截断调度、PPO 轮数与提交次数都不变。
- 倍率与 c 逐轮写入训练指标。检查点要保存 m，续训时恢复。

## 附录 A：探针期望值脚本
文件：`研究报告/analysis_20261108_f7/f7_probe_values.py`；运行：`python3 f7_probe_values.py`（只需 numpy）。

```python
"""F7 行为探针手算期望值（只读，无外部依赖，numpy）。
提前接近速率项（reward v5 新增项 approach_cbf）：
  b_k = c_k - d_safe；对执行路径相邻两点 k→k+1（时长 dt_k）：
  v_k = -[(b_{k+1}-b_k)/dt_k + gamma*(b_k+b_{k+1})/2]
  raw = -w * sum_k dt_k * clip(v_k, 0, vmax)
  回合预算：term = max(raw, -(B - used))，used 为本回合此前累计 |term|
参数：d_safe=0.30 m, gamma=1/3 s^-1, w=2.0, vmax=2.0 m/s, B=4.0
自适应学习率：m_0=10；每轮后按该轮 clip_fraction 均值 c：c<0.05 → m*1.5；c>0.15 → m/1.5；m 限制在 [1,50]
"""
import numpy as np
D, G, W, VMAX, B = .30, 1/3, 2., 2., 4.

def cbf_raw(c, dt):
    b = np.asarray(c, float) - D
```
