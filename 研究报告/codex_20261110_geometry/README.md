## 4. 仍有一对近重复，不能写成完全不同

测试`anticipatory__rl_test__front_offset_obstacle__000050`与实际验证`anticipatory__rl_val__front_offset_obstacle__000049`均为一个圆柱，xy=(0,3)：

| 项 | 测试000050 | 验证000049 |
|---|---:|---:|
| 半径（m） | 0.8307 | 0.8489 |
| 高度（m） | 4.4704 | 4.2577 |
| 中心z（m） | 2.2352 | 2.1289 |

底面在导出精度上同为地面；最大相对尺寸差`abs(a-b)/max(abs(a),abs(b))`为4.75796349%，以验证高度为分母则约4.9957%。因此它们不完全相同，但布局相同、尺寸接近。

此为诊断：同shape、xy一致至1e-6m、底面取1mm精度，尺寸差≤5%；不是新增的准入或删除规则。测试内部未发现该标准下的近重复。详细结果见`near_geometry_matches.csv`。本轮仍按用户已确定的186任务统计，不自行去除000050；是否据此限定论文“几何独立”表述交Claude。
