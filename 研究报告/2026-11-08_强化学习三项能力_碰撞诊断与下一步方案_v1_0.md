- 【事实】在 1 m 口径下，P6 的 139 次失败中有 138 次是碰撞。配对转移（BC → P6）：超时 → 成功 103 条；碰撞 → 碰撞 110 条；碰撞 → 成功 31 条；成功 → 碰撞 9 条；超时 → 碰撞 19 条。强化学习几乎消除了超时，但碰撞总数（141 → 138）没有下降。

## 2. 碰撞诊断：看得见，但反应太晚

| 指标（1 m 口径下的碰撞失败） | BC（141） | P6（138） | P9（148） |
|---|---:|---:|---:|
| 被撞障碍在碰撞前 2 个决策时已在相机视野内 | 56% | 85% | 86% |
| 被撞障碍在碰撞前 3 个决策时已在相机视野内 | 56% | 90% | 84% |
| 碰撞前曾进入视野 | 96% | 100% | 100% |
| 碰撞时飞行方向与机头朝向偏差 > 30° | 49% | 4% | 16% |
| 碰撞前 1 个决策的 8 步规划已穿过被撞障碍 | 52% | 77% | 77% |
| 碰撞前 2 个决策的 8 步规划已穿过被撞障碍 | 17% | 7% | 12% |
| 撞在障碍顶部附近（距顶 < 0.3 m） | 12 | 26 | 17 |

相机参数：水平视场 60°，量程 10 m，朝机体前方；视野判断忽略遮挡与竖直视场，属于近似。

- 【事实】对强化学习策略来说，被撞障碍在碰撞前 2–3 个决策（2.4–3.6 s）就已在视野内，机头也基本朝着飞行方向；但 8 步规划要到碰撞前 1 个决策才穿过它。规划长度约为 8 × 0.3 s，在当前速度下约 1.5–2 m。
- 【推断】失败的主要形式是**决策层面的反应过晚**：策略对障碍的反应只发生在规划范围内（约 1.5–2 m），障碍进入规划范围后只剩 1 个执行周期（1.2 s）来转向，来不及。BC 的碰撞中约一半属于侧飞时看不见障碍；强化学习修正了朝向，但没有学会提前转向。
- 【推断，未验证】可能的原因有两个，二者不互斥：
  - **H-执行周期：** 每个决策执行 4 步（1.2 s）才重新规划一次，看到障碍后修正的机会太少。部署时本来就是执行 2 步（`deployment_exec_horizon = 2`），训练和评价用的却是 4 步。
  - **H-reward：** 现有风险项只惩罚 0.45 m 以内的净空，接近惩罚 risk_close 只在 1.2 m 内起作用。在 2–4 m 外就朝障碍直飞的行为没有任何代价，只有最后的碰撞 −50 这一个稀疏信号。

## 3. 第一步：执行周期探针（只评价，不训练）

**目的：** 用最小的代价区分上面两个原因。如果只把每次执行的步数从 4 步改成 2 步（每 0.6 s 重规划一次），P6 的碰撞就明显减少，说明执行周期是主要杠杆，下一轮训练应改用 2 步执行，这也与部署一致。如果碰撞不减少，下一步转向 reward 侧的提前避障信号。

**登记：** 新评价协议 **#E3** = #E2 的全部设置，加上执行 2 步、重规划周期 0.6 s、每回合最多 120 个决策（物理时长仍为 72 s，与 #E2 相同）。只作诊断，不替代 #E2。

| 臂 | 策略 | 协议 | 评价集 |
|---|---|---|---|
| 对照 | P6@u256 | #E2（已有结果，复用） | dev420、val20 |
| 探针 | P6@u256 | #E3 | dev420、val20 |
| 参考 | P0 | #E3 | dev420（可选；用来判断 BC 本身是否也受益） |

同一组任务、同一重复、同一初态和回合种子，逐条配对。

**事先写定的判据（1 m 口径；工程门槛，不是统计检验）：**
1. dev420 碰撞失败数：#E3 ≤ #E2 − 15，并且
2. dev420 1 m 成功数：#E3 ≥ #E2，并且
3. val20 1 m 成功数：#E3 ≥ #E2 − 4。

- 三条都满足：判为"执行周期是有效杠杆"，下一轮训练方案以 2 步执行为处理臂。
- 只满足第 1 条：判为"不确定"，报告转移矩阵，由用户决定。
- 第 1 条不满足：判为"执行周期在本探针下不是主要杠杆"，下一轮转向 reward 侧方案（第 4 节）。

**补充的描述项：** 碰撞前规划穿过障碍的提前量分布；近距离擦过后的成功率；目标 > 3 m 的成功率是否下降。

**给 Codex 的实现要求：**
- 评价入口只在 #E3 下允许 `n_exec_steps = 2`、`max_episode_steps = 120`；#E2 的门禁逐项不变；
- 物理执行、碰撞与到达判定、去噪截断 2.0、噪声下限 0.1 全部不变；
- 回合记录中标明协议为 #E3；
- 核对单的 A 级条目：执行切片（2 步时取动作的哪几步）、120 决策的上限与 72 s 时长、#E2 不受影响的正反例。
- 预计 GPU 约 1–1.5 小时（P6 在 dev420 + val20 上各一次）。

## 4. 第二步（按探针结果二选一，届时另写方案）

- **A（探针有效）：** F7 = F3 + 2 步执行训练。父模型 P2@u128，seed 与 P9/P11 相同，训练到 u192。对照用 P9/P11；训练入口若需改代码，按 F6 的门禁经验先确认复用条件。
- **B（探针无效）：** F7 = F3 + 提前避障 reward。沿当前速度方向，对 2–4 m 内即将撞上的障碍给有界的提前惩罚，用于补上风险项和 risk_close 都覆盖不到的距离。系数先用训练域原迹标定检查，不用评价原迹。

两种方案都保留 v2 的其余各项，并配同父、同 seed、同预算的对照。

```python
"""Collision anatomy under the 1 m primary endpoint (dev420 #E2 traces; diagnosis for the next RL plan).
Usage: python3 -I collision_anatomy.py <project-repo-root> <traces-root> <out.json> bc P6 P9
traces-root = <project-repo>/jindu/routea_f5_run01/results/eval_dev/full ; each policy dir has traces/*.jsonl"""
import json, sys, os, ast, math, collections
repo, root, out = sys.argv[1], sys.argv[2], sys.argv[3]
sys.path.insert(0, os.path.join(repo, 'Improved-3D-Diffusion-Policy'))
from diffusion_policy_3d.env.collision_geom import segment_obstacle_collision, compute_obstacle_clearance, ObstacleSpec
TH = 0.1 + 2e-3                                   # physical threshold 0.1 m; +2 mm because executed paths stop at contact
def poly_hit(P, obs):
    for a, b in zip(P[:-1], P[1:]):
        h = segment_obstacle_collision(a, b, obs, TH)
        if h is not None: return h[1]
    return None
res = {}
for pol in sys.argv[4:]:
    d = os.path.join(root, pol, 'traces'); rows = []
    for f in sorted(os.listdir(d)):
        L = [json.loads(l) for l in open(os.path.join(d, f))]
        s, e = L[0], L[-1]
        task = s['task'] if isinstance(s['task'], dict) else ast.literal_eval(s['task'])
        g, s0 = task['goal_pos'], task['start_pos']; D0 = math.dist(g, s0)
        obs = [ObstacleSpec.from_dict(o) for o in s['geometry']]; byname = {o['name']: o for o in s['geometry']}
        T = [t for t in L[1:] if t.get('type') == 'transition']
        pts = [q for t in T for q in t['executed_path']]
        mind = min(math.dist(q, g) for q in pts)
        clear = [compute_obstacle_clearance(*q[:3], obs)[0] for q in pts[::2]]
        r = dict(task=s['task_id'], rep=s['repeat'], role=s['role'], out=e['done_reason'], n=len(T),
                 succ1m=mind < 1.0, goal_z=g[2], start_z=s0[2], D0=D0, min_clear=min(clear))
        if e['done_reason'] == 'collision' and not r['succ1m']:
            k = len(T) - 1; last = T[-1]['executed_path']; p = last[-1]
            name = poly_hit(last, obs)
            if name is None: kind, top = ('ground' if p[2] < 0.3 else 'unresolved'), None
            else:
                o = byname[name]; top = o['z'] + o['height'] / 2 if o['shape'] == 'cylinder' else o['z'] + o.get('size_z', 0) / 2
                kind = 'top' if p[2] > top - 0.3 else 'side'
            lead = 0                                # consecutive decisions before k whose 8-step plan already crosses the hit obstacle
            for j in range(k - 1, -1, -1):
                h = poly_hit(T[j]['planned_policy_path'], obs)
                if h is not None and (name is None or h == name): lead += 1
                else: break
            dens = sum(1 for o in obs if compute_obstacle_clearance(*p[:3], [o])[0] < 2.0)
            r.update(kind=kind, obstacle_shape=byname[name]['shape'] if name else None, k=k, lead=lead,
                     d_goal=math.dist(p, g), progress=1 - math.dist(p, g) / D0, local_density_2m=dens,
                     z_at_hit=p[2], obstacle_top=top)
        rows.append(r)
    res[pol] = rows
json.dump(res, open(out, 'w'))
def pct(a, b): return '%d/%d (%.0f%%)' % (a, b, 100 * a / b) if b else '0/0'
for pol, R in res.items():
    C = [r for r in R if r['out'] == 'collision' and not r['succ1m']]
    print('==', pol, '| 1 m success', pct(sum(r['succ1m'] for r in R), len(R)), '| collision failures', len(C),
          '| timeout failures', sum(1 for r in R if r['out'] == 'time_limit' and not r['succ1m']))
    print('  hit kind', dict(collections.Counter(r['kind'] for r in C)), '| obstacle shape', dict(collections.Counter(r['obstacle_shape'] for r in C)))
    ks = sorted(r['k'] for r in C); print('  collision decision k: median %d, k<=2: %s, k<=5: %s' % (ks[len(ks) // 2], pct(sum(x <= 2 for x in ks), len(ks)), pct(sum(x <= 5 for x in ks), len(ks))))
    L_ = collections.Counter(min(r['lead'], 4) for r in C)
    print('  plan already crosses the hit obstacle for >=1 / >=2 / >=3 decisions before impact: %s / %s / %s; lead dist %s' % (
        pct(sum(r['lead'] >= 1 for r in C), len(C)), pct(sum(r['lead'] >= 2 for r in C), len(C)), pct(sum(r['lead'] >= 3 for r in C), len(C)), dict(sorted(L_.items()))))
    pr = sorted(r['progress'] for r in C); dg = sorted(r['d_goal'] for r in C)
    print('  progress at impact: median %.2f, p25 %.2f, p75 %.2f | distance to goal median %.1f m' % (pr[len(pr) // 2], pr[len(pr) // 4], pr[3 * len(pr) // 4], dg[len(dg) // 2]))
    dn = collections.Counter(min(r['local_density_2m'], 4) for r in C); print('  obstacles within 2 m of impact (4=4+):', dict(sorted(dn.items())))
    print('  by role:', {ro: '%s coll' % pct(sum(1 for r in R if r['role'] == ro and r in C), sum(1 for r in R if r['role'] == ro)) for ro in sorted(set(r['role'] for r in R))})
    near = [r for r in R if r['min_clear'] < 0.3]
    print('  close calls (min clearance < 0.3 m): %d episodes, of which 1 m success %s' % (len(near), pct(sum(r['succ1m'] for r in near), len(near))))
    for lab, f in (('goal z<=3', lambda r: r['goal_z'] <= 3), ('goal z>3', lambda r: r['goal_z'] > 3), ('D0<15m', lambda r: r['D0'] < 15), ('D0>=15m', lambda r: r['D0'] >= 15)):
        S = [r for r in R if f(r)]; print('  %-10s 1 m success %s, collision %s' % (lab, pct(sum(r['succ1m'] for r in S), len(S)), pct(sum(1 for r in S if r in C), len(S))))
if 'bc' in res and 'P6' in res:
    A = {(r['task'], r['rep']): r for r in res['bc']}; B = {(r['task'], r['rep']): r for r in res['P6']}
    cnt = collections.Counter(('S' if A[k]['succ1m'] else ('C' if A[k]['out'] == 'collision' else 'T')) + '->' +
                              ('S' if B[k]['succ1m'] else ('C' if B[k]['out'] == 'collision' else 'T')) for k in A)
    print('== paired BC -> P6 (1 m; S success, C collision, T timeout):', dict(sorted(cnt.items())))
```

```python
"""Was the obstacle that is eventually hit inside the depth camera's horizontal field of view before impact?
Camera (diffusion_policy_3d/model/common/synth_pointcloud.py): HFOV 60 deg, far 10 m, looking along body x (yaw).
Approximation: obstacle 'in view' at a decision if the bearing from the drone to the obstacle's nearest horizontal point
lies within +-30 deg of yaw and that point is within 10 m (vertical FOV ignored; obstacles are tall prisms).
Also reports the angle between flight direction (executed segment) and yaw at impact.
Usage: python3 -I collision_visibility.py <project-repo-root> <traces-root> bc P6 P9"""
import json, sys, os, ast, math, collections
repo, root = sys.argv[1], sys.argv[2]
sys.path.insert(0, os.path.join(repo, 'Improved-3D-Diffusion-Policy'))
from diffusion_policy_3d.env.collision_geom import segment_obstacle_collision, ObstacleSpec
TH = 0.1 + 2e-3
def wrap(a): return (a + math.pi) % (2 * math.pi) - math.pi
def nearest_xy(o, p):
    if o['shape'] == 'cylinder':
        dx, dy = p[0] - o['x'], p[1] - o['y']; r = math.hypot(dx, dy) or 1e-9
        return (o['x'] + dx / r * o['radius'], o['y'] + dy / r * o['radius'])
    c, s = math.cos(-o['yaw']), math.sin(-o['yaw']); lx = (p[0] - o['x']) * c - (p[1] - o['y']) * s; ly = (p[0] - o['x']) * s + (p[1] - o['y']) * c
    lx = max(-o['size_x'] / 2, min(o['size_x'] / 2, lx)); ly = max(-o['size_y'] / 2, min(o['size_y'] / 2, ly))
    c, s = math.cos(o['yaw']), math.sin(o['yaw']); return (o['x'] + lx * c - ly * s, o['y'] + lx * s + ly * c)
def in_view(o, pos, yaw):
    q = nearest_xy(o, pos); d = math.hypot(q[0] - pos[0], q[1] - pos[1])
    if d < 1e-6: return True
    return d <= 10.0 and abs(wrap(math.atan2(q[1] - pos[1], q[0] - pos[0]) - yaw)) <= math.radians(30)
for pol in sys.argv[3:]:
    d = os.path.join(root, pol, 'traces'); vis = collections.Counter(); mis = []; n = 0
    for f in sorted(os.listdir(d)):
        L = [json.loads(l) for l in open(os.path.join(d, f))]
        s, e = L[0], L[-1]
        if e['done_reason'] != 'collision': continue
        task = s['task'] if isinstance(s['task'], dict) else ast.literal_eval(s['task'])
        g = task['goal_pos']; T = [t for t in L[1:] if t.get('type') == 'transition']
        if min(math.dist(q, g) for t in T for q in t['executed_path']) < 1.0: continue   # 1 m success, not a failure
        obs = [ObstacleSpec.from_dict(o) for o in s['geometry']]; byname = {o['name']: o for o in s['geometry']}
        last = T[-1]['executed_path']; name = None
        for a, b in zip(last[:-1], last[1:]):
            h = segment_obstacle_collision(a, b, obs, TH)
            if h: name = h[1]; break
        if name is None: continue
        n += 1; o = byname[name]
        for back in (1, 2, 3, 4):
            j = len(T) - 1 - back
            if j >= 0 and in_view(o, T[j]['pre_state']['position'], T[j]['pre_state']['yaw']): vis[back] += 1
        seen_any = any(in_view(o, t['pre_state']['position'], t['pre_state']['yaw']) for t in T[:-1])
        vis['ever_before_impact'] += seen_any
        a, b = last[0], last[-1]; heading = math.atan2(b[1] - a[1], b[0] - a[0])
        mis.append(abs(math.degrees(wrap(heading - T[-1]['pre_state']['yaw']))))
    mis.sort()
    print('== %s collision failures with identified obstacle: %d' % (pol, n))
    print('  hit obstacle in camera view at 1/2/3/4 decisions before impact: %s' % ' / '.join('%d (%.0f%%)' % (vis[k], 100 * vis[k] / n) for k in (1, 2, 3, 4)))
    print('  ever in view before impact: %d (%.0f%%)' % (vis['ever_before_impact'], 100 * vis['ever_before_impact'] / n))
    print('  |flight direction - yaw| at impact: median %.0f deg, >30 deg: %d (%.0f%%), >60 deg: %d (%.0f%%)' % (
        mis[len(mis) // 2], sum(x > 30 for x in mis), 100 * sum(x > 30 for x in mis) / n, sum(x > 60 for x in mis), 100 * sum(x > 60 for x in mis) / n))
```
