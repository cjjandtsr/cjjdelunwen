## 一、为什么做这两项

### 1.1 更新幅度小【事实】与学习率假设【工程假设】
- 【事实，附录 B】P9、P11 在 u129—u192 共 128 轮的记录：approx KL 每轮均值的中位数约 8e-7；clip_fraction 每轮均值的中位数为 0 和 1e-5，128 轮中 74 轮恰为 0；概率比均值的最小值 0.999。LoRA 学习率为 1.5e-5→1.25e-5。每轮采集约 330 s，更新约 34 s，采集占 91%。
- 这些指标按本实现定义：逐维 log-prob 先夹到 [−5, 2]，再对 8 步 × 11 维取平均；记录的是每次 optimizer.step 之前 2560 对的平均值。官方 DPPO 的损失结构相同，但目标 clip 比例不能直接跨任务移植。
- 【工程假设，待本实验检验】在现有截断与保持项下提高 actor 学习率，能更快把 reward 信号转成行为改变。这不是已经定位的根因：P6 在 256 轮内大幅改变了到达行为，说明策略并非动不了。表示能力、探索范围、保持项梯度、log-prob 饱和、信用分配都可能是限制因素。
- 【文献】rsl_rl 按目标 KL 自适应调学习率；DPPO 仓库说明提高 actor 学习率能提高样本效率；LoRA 学习率约为全参数微调的 10 倍（LLM 上的经验，不是 UAV 强化学习的验证）。本方案改用 clip_fraction 作反馈，固定上下限，并迟一轮生效，属于本项目的改造。

### 1.2 现有风险项只在很近处起作用【事实】
- reward v2 的风险项对执行段与计划尾段（第 5—8 段，按 2^(−(j−4)/4) 衰减）都打分，但只在净空 < 0.45 m 时非零，每决策取最大值，幅度 ≤ 1，终止决策不计尾段。
- v3 接近项 `risk_close` 的实际作用范围约在 1.3 m 内。dev420 实测 P6 分段速度中位数 0.63 m/s，每决策前进 0.75 m（附录 C1）。按这个速度正面接近：决策起点净空 2.0 m 时 v2、v3 都为 0；1.6 m 时 v2 为 0，v3 为 −0.097（附录 C2）。
- 【项目事实】P6 在 dev420 的碰撞中，被撞障碍在碰撞前 2—3 个决策已在视野内（85%—90%），但 8 步规划到前 1 个决策才穿过它（77%）。
- 【推断】这支持尝试更早的安全信号，但不能排除 1.1 节列出的其他限制。

### 1.3 采用的做法【文献】
- 控制屏障函数（CBF）型安全奖励 clip(ḃ + γb, −c, 0)：arXiv 2602.08653 表 I 显示，在 3、5 m/s 下它把成功率从 62.25%、67.75% 提到 84.50%、94.00%；在 7、9 m/s 下反而下降。该论文的完整方法还包含部署时的安全修正，本项目只取其中的奖励项，不能把它的完整成绩当作本项目的预期。

## 三、reward v5：提前接近速率项 `approach_cbf`

### 3.1 定义
对每个决策实际执行的路径，碰撞或入球时取截断到首次事件的路径（复用 `environment.py` 已有的截断路径、`event_fraction`、`executed_time_s`，以及 space 项的逐段 Δt，末段按比例缩放）：
- c_k：点 p_k 到最近障碍的净空，调用 `_obstacle_clearances(np.stack((p, p)), obstacles)`，与 v3 `closing_cost` 相同；只含障碍，不含地面。
- b_k = c_k − d_safe。
- 每段：若 Δt_k = 0，贡献记 0；否则 v_k = −[(b_{k+1} − b_k)/Δt_k + γ (b_k + b_{k+1})/2]，贡献 = Δt_k × clip(v_k, 0, v_max)。
- `approach_cbf` = −w × Σ_k 贡献。
- 总 reward = v2 总和 + `approach_cbf`；v2 五项与系数完全不变；invalid_state 决策该项记 0。
- **不设回合预算，也不跨决策累计。** 该项只由本决策的执行路径和世界几何决定，与评论家看到的状态是同一类信息（和 v2 风险项一样使用特权几何，只用于 reward）。

| 参数 | 值 | 含义 |
|---|---|---|
| d_safe | 0.30 m | 碰撞判定 0.10 m 之外再留 0.20 m |
| γ | 1/3 s⁻¹ | 时间余量 3 s：按当前接近速度，3 s 内会贴近安全裕度就开始扣分 |
| w | 2.0（标定备选 1.0） | 系数 |
| v_max | 2.0 m/s | 单段违反量上限 |

### 3.2 性质
- 【推导】若始终满足 ḃ ≥ −γb，则 b(t) ≥ b(0)e^(−γt)，余量不会降到 0。本项惩罚违反这一条件的程度，是软约束，不是安全证明。端点差分可能漏掉段内先靠近后远离的情形，这部分仍由 v2 的逐段风险项覆盖。
- 开始扣分的净空约为 d_safe + v/γ = 0.3 + 3v：0.63 m/s 时 2.2 m，1 m/s 时 3.3 m（附录 C2）。
- 切向掠过（净空 ≥ d_safe）、远离、减速都不扣分。**减速同样能消除惩罚**，所以 reward 下降不等于学会了提前绕行，必须看 §6 的行为分解。
- 单决策 |term| ≤ w × 1.2 × v_max = 4.8（w = 2）。
- 取消预算后，"到达回报高于超时回报"不再有最坏情况保证（最坏情况下逐决策累计可超过 100）。改由 §3.3 的经验检查控制：到达回合的典型回报约 +108（2026-11-03 reward 审计，P6 dev420 中位数），超时约 +6，正常飞行中本项的累计远小于两者之差。

### 3.3 开训前的标定检查（预先写定，Claude 计算）
- **数据：** P6 第二阶段训练采集记录（u129—u256，训练域，不用评价原迹）。记录中没有 `executed_path`，按 `env/traj_utils.py` 的定义重建：动作前三维是世界系逐步位置增量，从决策起点按原 float32 逐步累加，得到执行点。
- **重建前先验证（Codex 做，结果写入核对单）：** 重建终点与记录的决策后位置一致；首次事件截断与记录的结局一致；用重建路径算出的 space 成本与记录一致。不一致的决策剔除并计数；剔除超过 1% 时停下来报告。重建资料标为"重建"，不当作原始路径。
- **样本：** 只用完整回合（同一 episode ID 去重，核对起点和终点）。采集边界处被截断的片段单列，不当作超时，也不当作完整回合。
- **规则：** 对完整的到达回合计算每回合 `approach_cbf` 之和（w = 2）。中位数 ≥ −2.0 且有符号的 10% 分位（即惩罚最重的 10% 回合的边界）≥ −8.0 时用 w = 2；否则用 w = 1。完整到达回合少于 50 个时也用 w = 1。选定后四臂统一登记，不再调参。
- 同时报告：碰撞、超时回合的同一统计；每决策该项非零的比例。

## 四、自适应学习率（只作用于 F7 臂的 actor）
- 倍率 m 的初值为 5，u257 即用 5e-5。
- 每个外层更新结束后，读取该轮 20 次提交记录的 `clip_fraction` 均值 c（提交前指标）。c < 0.05 → m × 1.5；c > 0.15 → m ÷ 1.5；其余不变。m 限制在 [1, 20]，即学习率在 1e-5 到 2e-4 之间。新的 m 用于下一轮。
- 评论家学习率、截断调度、PPO 轮数、提交次数都不变。
- **检查点语义：** 每个检查点同时保存"本轮已用的 m"和"下一轮将用的 m"。续训时直接取后者，不再乘一次。复用现有 `save.py` 的 schedules 容器，不新造格式。
- 每轮写入训练指标：c、m（已用与下一轮）、approx KL、概率比的最小值和最大值。

## 六、评价与预先登记判据
- **协议：** #E2（截断 2.0、确定性采样、LoRA 分支）。dev420（训练世界，非未见）与 val20（20 个世界、80 个任务、每任务 1 次，共 80 条件，只作描述）。结论只限开发集，不宣称未见环境泛化改善。
- **1 m 结局（每回合互斥）：** 沿用论文线的连续路径首次入球函数。执行路径在任何碰撞之前进入目标 1 m 记为成功，之后再发生的碰撞不改变结局；在进入 1 m 之前碰撞记为碰撞；其余为超时。0.5 m 的原环境结局另行保留。
- **统计：** F7 − 对照，按 task × repeat 配对，两个 seed 合并（每臂 840 条记录）。95% 区间用世界聚类 bootstrap：每次整簇重抽世界，同一次抽样保留两个 seed 在该世界的全部配对；20000 次，seed 2026102601（沿用已登记口径）。该区间不估计任意训练 seed 的总体方差。同时报告 P18 − P19 作为运行间差异。

**判定（按顺序检查，命中即停）：**

| 顺序 | 判定 | 条件（dev420，1 m） |
|---|---|---|
| 0 | 无结论 | 任一臂硬故障或评价未完成：报告原因，不判定 |
| 1 | 符合采纳标准 | 合并的到达率差区间下界 > 0，**且**合并碰撞率差的点估计 < 0，**且**两个 seed 对的到达率差点估计都 > 0 |

```python
"""F7 v1_2 行为探针手算期望值（只读，numpy）。
提前接近速率项 approach_cbf（v1_2：无回合预算，只依赖本决策的执行路径与几何）：
  b_k = c_k - d_safe；对执行路径相邻两点 k→k+1（时长 dt_k）：
  dt_k = 0 的段贡献记 0；否则 v_k = -[(b_{k+1}-b_k)/dt_k + gamma*(b_k+b_{k+1})/2]
  term = -w * sum_k dt_k * clip(v_k, 0, vmax)
参数：d_safe=0.30 m, gamma=1/3 s^-1, w=2.0（标定备选 1.0）, vmax=2.0 m/s
自适应学习率（v1_2）：m_0=5；每轮后按该轮 clip_fraction 均值 c：c<0.05 → m*1.5；c>0.15 → m/1.5；m 限制在 [1,20]
"""
import numpy as np
D, G, VMAX = .30, 1/3, 2.

def cbf(c, dt, w=2.):
    b = np.asarray(c, float) - D; dt = np.asarray(dt, float); tot = 0.
    for k in range(len(dt)):
        if dt[k] == 0: continue
        v = -((b[k+1] - b[k]) / dt[k] + G * (b[k] + b[k+1]) / 2)
        tot += dt[k] * min(max(v, 0.), VMAX)
    return -w * tot

def line(c0, speed, n=4, dt=.3):
    return [c0 - speed * dt * k for k in range(n + 1)], [dt] * n

cases = [
    ("正面接近 0.45 m/s，起点净空 1.6 m", *line(1.6, .45)),
    ("正面接近 0.45 m/s，起点净空 1.3 m", *line(1.3, .45)),
    ("正面接近 0.45 m/s，起点净空 2.5 m（应为 0）", *line(2.5, .45)),
    ("减速到 0.10 m/s，起点净空 1.0 m（应为 0）", *line(1.0, .10)),
    ("切向掠过，净空恒 0.5 m（应为 0）", [.5] * 5, [.3] * 4),
    ("切向掠过，净空恒 0.25 m（b<0）", [.25] * 5, [.3] * 4),
    ("远离障碍 0.45 m/s，起点 0.8 m（应为 0）", [0.8 + .45 * .3 * k for k in range(5)], [.3] * 4),
    ("碰撞截断：两段 0.3 s + 一段 0.1 s", [0.40, 0.25, 0.12, 0.10], [.3, .3, .1]),
    ("首点即事件：零时长段（应为 0，无 NaN）", [0.10, 0.10], [0.]),
    ("零时长段夹在中间：0.3 s + 0 s", [0.60, 0.465, 0.465], [.3, 0.]),
]
for name, c, dt in cases:
    print("%-40s w=2: %.6f   w=1: %.6f" % (name, cbf(c, dt), cbf(c, dt, 1.)))
print("单决策上界 |term| ≤ w*1.2*vmax = %.3f（w=2）" % (2 * 1.2 * VMAX))

def lr_mult(seq, m=5.):
    out = [m]
    for c in seq:
        if c < .05: m = min(m * 1.5, 20.)
        elif c > .15: m = max(m / 1.5, 1.)
        out.append(m)
    return out
s = [0.0, 0.0, 0.20, 0.08, 0.03, 0.0, 0.0, 0.0, 0.0]
print("clip_fraction 序列", s)
print("倍率序列（第 1 个为 u257 所用）", ["%.6g" % x for x in lr_mult(s)])
```
