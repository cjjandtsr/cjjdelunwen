## 一、要回答的问题

P6 的能力本身可复现：评价是确定性采样，训练外世界上也保持了优势。不确定的是**同一配方能否重复得到这种提升**。现有的继续训练结果按代码版本分开如下：

| 代码版本 | 运行 | O 到达（P2 = 261） |
|---|---|---|
| A2 版本（u128 处重启） | P4（无保持项）273；P6（有保持项）289 | 都高于 P2 |
| F5 版本 | P9 259；P11 216 | 都不高于 P2 |
| B2560 原版本（不中断） | P3：dev420 #E1 下由 160 降到 129 | 未评 O |

这些结果有两种解释，现有数据区分不了：
1. 继续训练的运行间差异很大，P6 正好是好的一次；
2. A2 版本代码与 F5 版本之间存在影响训练行为的差别。

本实验在 **A2 版本代码**下，用 P6 的配方和一个新 seed 再训练一次。

## 四、预先登记判据（写于运行之前）

记新运行在 O 上的到达数为 N（满分 540），P2 为 261，P6 为 289。统计口径与 G16 相同：世界聚类 bootstrap，20000 次，seed 2026102601。下列界限是工程阈值，不是统计显著性检验。界限取 P6 相对 P2 增益的一半，即 N ≥ 275（相对 P2 至少 +2.6 个百分点）。

| 结果 | 判定 | 论文写法 |
|---|---|---|
| N ≥ 275，且 N − P0 的区间下界 > 0 | **符合采纳标准** | P6 保持为本文方法；写"同一代码版本下的两次运行都高于第一阶段"，报告两次的数值；P9、P11 作为另一代码版本的运行单独说明（结合 Codex 的 H11 分类） |
| 262 ≤ N ≤ 274 | **不确定** | 第二阶段的提升没有重复出来。本文方法改为第一阶段后训练，第二阶段与保持正则写成"延长训练的稳定性"分析 |
| N ≤ 261 | **本预算下不符合采纳标准** | 同上，并写明 A2 版本代码下继续训练也会出现不高于第一阶段的结果 |

**描述项（不作判据）：**
- 按稀疏、适中、密集三类给出到达、碰撞、超时；
- 路径效率中位数，检查保持项"维持路径效率"在第四次运行上是否仍成立；
- 新运行 − P6 的配对差，作为同代码版本下的运行间差异。

**写作约定：** 无论结果如何，新运行都进入论文（消融表注或补充材料），不因结果不利而删除。
