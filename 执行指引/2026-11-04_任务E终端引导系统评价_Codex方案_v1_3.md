## 一、目的与写作边界

**问题（事实）。** P6@u256 的超时几乎都在目标附近：四个评价集共 197 次超时，回合内最近目标距离全部 <2 m，其中 177 次 <1 m。合并训练外世界稀疏类中 P6 到达 208/295，未到达以超时为主（64 次），而直线飞行参考在该类全部到达。

**做法。** 分层系统：扩散策略负责导航；当执行路径首次进入距目标 r 以内时，由一段与已执行路径平滑衔接、不读障碍的终端轨迹接管。策略不改、不重训。

**要回答：** ①终端引导能否提高系统到达率、是否引入新失败；②系统层面后训练相对 BC 的提升是否保持；③r 从 1 m 到 2 m 的变化（描述性）。

**写作边界：** 结果写在 4.2.8 节"分层终端引导"与 4.4 讨论。系统到达率与策略到达率并列、分开报告；引导结果不作为 C2、C3、C3b、R1 的证据，也不进入论文主结论（策略能力）的任何表格。局限中写明"引导不感知障碍"。

## 二、引导合同（运行前写死，不调参）

### 2.1 触发与事件顺序
每个 0.3 s 执行段（策略段）执行后，按以下顺序处理：
1. 先按首次事件合同（`first_event.py::locate_first_event`，机体半径 0.1 m，目标球 0.5 m，地面 0.2 m，`terminate_at_space_limits=False`，容差内同刻失败优先）判定该段内是否发生到达、碰撞、触地。发生则回合结束，**不触发**。
2. 再判期限（§2.5）。到期则以超时结束，不触发。
3. 都未发生，且段末位置到目标中心的距离 d 第一次 ≤ r，则触发；本决策剩余的策略段全部丢弃，此后不再调用策略。
- 主臂 r = 2.0 m，敏感性臂 r = 1.0 m，均在任何引导结果之前固定，两臂都报告、不择优。

### 2.2 衔接状态：取自实际执行折线
记已执行折线的最近三个段末点为 $p_{k-2},p_{k-1},p_k$（段长 Δ = 0.3 s）。
- $v_k=(p_k-p_{k-1})/\Delta$；$a_k=(p_k-2p_{k-1}+p_{k-2})/\Delta^2$。
- 触发只在段末检查，所以至少已执行 1 段；只执行了 1 段时 $p_{k-1}$ 取回合起点、$a_k=0$。
- 不使用动作中的名义速度、加速度分量。

### 2.3 轨迹与时长
1. **形式：** 每轴五次多项式（最小加加速度），$p(0)=p_k,\ \dot p(0)=v_k,\ \ddot p(0)=a_k,\ p(T)=g,\ \dot p(T)=0,\ \ddot p(T)=0$。参考四旋翼轨迹生成中的单段最小加加速度轨迹；EGO-Planner 以 B 样条做平滑与可行性优化，单段无障碍情形与此目标一致，本方案不含其障碍项。
2. **初始时长：** $\bar v=\mathrm{clip}(\|v_k\|,\ 0.5,\ \min(1.0,\ v_{\max}))$ m/s；$T_0=\max(0.6\,\mathrm{s},\ d/\bar v)$，向上取整到 0.3 s 的整数倍；若 $v_{\max}<0.5$，取 $\bar v=v_{\max}$。
3. **可行性：** 合速度峰值 $\le \max(v_{\max},\|v_k\|)$ 且合加速度峰值 $\le \max(a_{\max},\|a_k\|)$。峰值解析求取：对 $\|\dot p\|^2$、$\|\ddot p\|^2$ 求导后用多项式求根，取 $[0,T]$ 内驻点与端点的最大值。不满足则 $T\leftarrow T+0.3$ s，重复。
4. **时长搜索与期限（v1_3 写死）：** 记 $T_{\mathrm{avail}}=72\,\mathrm{s}-t_{\mathrm{trig}}$，$T_{\mathrm{cap}}=\max(T_0,\ \lceil T_{\mathrm{avail}}/0.3\rceil\times0.3)$。
   - 依次检查 $T=T_0,\ T_0+0.3,\ \dots$，直到 $T\le T_{\mathrm{cap}}$ 的最后一个值；第一个满足第 3 条的 $T$ 即 $T_{\mathrm{final}}$，`limit_violated=false`。
   - 全部不满足：$T_{\mathrm{final}}$ 取最后检查的值，`limit_violated=true`；数据包保留其峰值，不得称为可行轨迹。
   - 与可行性无关地，若 $T_{\mathrm{final}}>T_{\mathrm{avail}}$，`deadline_truncated=true`：仍按 $T_{\mathrm{final}}$ 的曲线执行，到 72 s 时按 §2.5 判定（途中入球即到达）。
   - `limit_violated` 或 `deadline_truncated` 的回合若属 E2 的损失或新增失败，照常计入。
5. **上限来源：** $v_{\max}$、$a_{\max}$ 取冻结 EGO 示范数据中，按 0.3 s 采样的弦速度 $\|p_{j+1}-p_j\|/\Delta$ 与弦加速度 $\|p_{j+1}-2p_j+p_{j-1}\|/\Delta^2$ 的 99 分位数（全部示范、全部时刻）。由 Codex 只读计算，并在核对单中锁定以下输入后给出值、样本量与脚本：
   - 数据路径与文件 hash；位置字段名与坐标系（必须是每回合内固定的坐标系；若为随机体移动的坐标系，先换算到世界或里程计坐标系）；
   - 原始时间间隔；若不是 0.3 s，按时间戳对位置线性插值重采样到 0.3 s，写明规则；
   - 回合边界：差分不跨回合，回合首尾不足的点不计；
   - 分位数算法：`numpy.quantile(…, 0.99, method="linear")`。
   两个启动文件的配置值一并列出作参照。不得从任何评价集原迹取值。

### 2.4 执行
- 引导轨迹以 0.05 s 细分为弦，逐弦送入首次事件合同（同一机体半径、目标球、地面阈值）；对外仍按 0.3 s 为一个"引导段"计数与记录，每个引导段含 6 条细分弦。最后一段截止于 $t=T$；若 $t=T$ 时尚未入球（不应发生，因终点为目标中心），在目标中心悬停至期限。
- 偏航保持触发时的值。触发后不再合成策略观测；执行路径、事件与几何统计照常记录。
- 引导不读障碍、不做碰撞检查。

### 2.5 物理时钟与期限
- 物理时钟逐段（策略段 0.3 s、引导细分弦 0.05 s）累加，期限 72 s（即原 60 次决策 × 1.2 s）。
- 事件时刻 t ≤ 72 s 的到达、碰撞、触地有效；72 s 时刻同时发生的到达与超时，按到达处理（与原合同"第 60 次决策内的事件有效"一致）；碰撞与到达同刻按原合同失败优先。
- 未触发回合的期限判定必须与纯策略原迹完全一致（E-A1、§六全量一致性）。

### 2.6 实现边界
- 引导与逐段调度写在**评价侧新模块**中，不修改受身份保护的环境与训练源码闭包（`kinematic_uav_env.py`、`reward_v2_support/*`、`first_event.py` 等）；运行前后闭包文件 SHA 不变。首次事件判定以函数调用方式复用。
- 事务边界：每次决策的 H4 先按 `step_v2` 的方式一次性转换为航点，再逐段消费；噪声抽取次序、观测种子与顺序、决策计数、动作采样种子与 `step_v2` 相同。
- P0 走基座分支，P6 走 LoRA 分支，#E2（截断 2.0、标准差下限 0.1×11、确定性采样）。

### 2.7 几何事实与安全表述（Claude 计算：`研究报告/analysis_20261104/goal_clearance.py`，输出 `goal_clearance_out.txt`）
- 全部 272 个任务中，目标点到最近障碍表面的距离最小为 1.55 m；目标高度最小 1.51 m。
- r = 1.0 m 臂**预期低风险**：充分条件是实际引导轨迹不离开以目标为心、半径 1.4 m 的球，此时不可能碰撞；但多项式可能超调，触地也须单独核查，须以实测的最大离开距离、最低高度和逐例碰撞、触地统计验证。论文分开写"充分条件"与"实际结果"。
- r = 2.0 m 臂：11 个任务（dev420 6、val20 2、test12 2、扩展集 1）的目标 2.1 m 内有障碍表面，引导可能碰撞；目标高度 1.51 m 时轨迹最低点可能接近地面阈值。

O = test12（240 回合）∪ 扩展集（300 回合），共 540 回合、32 个世界（表头写明）。配对单位为（任务，重复）；区间为按世界聚类的 bootstrap 95% 区间（20000 次，种子 2026102601）；世界数 <5 的格只报计数。以下界限都是写作门槛，不是显著性检验。计数单位均为回合（首次事件合同下每回合至多一个终止事件）。

**E1（主要）：** Δ = O 上 P6+TG2 系统到达率 − P6 纯策略到达率。
- 区间下界 > 0：写"终端引导提高了系统到达率"，同时报告策略到达率不变；
- 点估计 > 0 且区间含 0：写"方向为正但不确定"；
- 点估计 ≤ 0：如实报告并逐例分析引导段失败。

**E2（代价）：** 在 O 上对 P6+TG2 按回合计数（四类互不重叠）：
- R 挽回：策略未到达 → 系统到达；
- L 损失：策略到达 → 系统未到达（其中引导段碰撞或触地的回合数记 C）；
- N 新增碰撞：策略超时 → 系统碰撞或触地；
- 另报告"策略碰撞 → 系统碰撞或触地"（失败类型不变，不计为代价）。

写作门槛：
- R > 0 且 (L + N) ≤ 0.10·R：写"引导几乎不引入新的失败"；
- R > 0、L ≤ 0.10·R 但 (L + N) > 0.10·R：写"原成功回合流失较少，但引导在原超时回合中新增 N 次碰撞或触地"，写入局限；
- 其余情况（含 R = 0）：如实报告各计数，写入局限。
- C、N 及全部引导段碰撞、触地回合总是逐例列出（世界、类别、障碍）。

**E3（系统层面后训练提升）：** O 上 P6+TG2 − P0+TG2 的系统到达率配对差。区间下界 > 0 写"加入相同的终端引导后，后训练相对 BC 的提升仍然成立"；点估计 > 0 且区间含 0 写"方向为正但不确定"；否则如实报告。与纯策略层面的 P6 − P0（+18.9 [10.7, 27.1]）并列。

**描述性报告（不设判据）：**
- 敏感性：P6+TG1 与 P6+TG2 在 O 上的系统到达、R、L、C 并列。
- 引导占比：触发回合中引导时长与路径长度占系统全程的比例，报中位数与 10/90 分位数。
- 平滑性：主指标为衔接处"最后一条策略弦方向"与"第一条引导细分弦方向"的夹角（任一弦长度为 0 时夹角无定义，记空值，不计入分母，单独报告空值回合数）；对照为同回合策略自身相邻弦夹角的分布，以及同一触发点若改用 v1_0 直线引导时的衔接夹角（只用几何离线计算，不重跑评价）。辅指标为衔接处弦速度差。
- 可行性：`limit_violated` 回合数、迭代次数分布、最终峰值。
- 引导轨迹离开触发球的最大距离、最低高度。
- 按稀疏、适中、密集分别给出策略到达与系统到达；dev420、val20 另报。

## 六、验收

**硬条件：**

2. 每个（系统，评价集）回合数等于分母；`initial_hash` 与 bank 配对不符 0。
3. 全量一致性：未触发回合的系统结局、决策数、执行路径、观测 hash 与纯策略原迹完全相同，不一致数 = 0；触发回合在触发时刻之前逐位相同。
