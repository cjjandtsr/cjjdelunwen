## 三、数据
**评价集 U：**`x1/x1_states.json` 的 83 个状态，顺序、观测、种子与 X1 完全相同（确定性种子 2026112400 + 序号）。P6 的 b_P6、g_P6 直接取 `x1/x1_raw_run甲.pt` 中 `b['P6']`、`g['P6']`，不重算。

**训练集 T：**
- 来源：P28、P35、P36 在 u264 检查点 `state['schedules']['f9_session']['snapshot']` 所指的缓冲区快照中的 `records`（不是 `heldout`），先核对快照 SHA256 等于 `snapshot_sha256`。取法与 `run_routea_f9.freeze_holdout` 相同。
- 按 `observation_sha256` 去重；剔除与 U 中任一状态 SHA 相同的记录（应为 0 条，若不为 0 照样剔除并报数）。
- 顺序：P28 → P35 → P36 的原顺序拼接后去重，序号 j。
- 观测、决策前状态、条件：用 X1 的 `prepare`（`observation_adapter.encode` + `pre_state`），条件最大差必须为 0。

**训练目标：**对每个训练状态，用 P6（训练前）跑一次确定性成对链，种子 2026112600 + j，设置 g1（d_safe 0.6、η 0.4、M 4）：
- y_j = `normalize(out['full'])[0]`（引导后），同时存 b0_j = `normalize(out['base_full'])[0]`。
- 只在训练开始前生成一次，存为 `x2_targets.pt`，两个臂共用。**目标是 P6 的引导输出，不随训练更新。**

**遗忘描述集 R：**A2 参考库（`plan['reference']`，549 条，`conditions` 为 576 维）。对每条用 P6 跑确定性非引导链，种子 2026112700 + k。条件字典的构造方式与 X1 中 `encoded.condition` 的键集相同；若缺键或不知如何构造，**跳过 R 并在回传中说明**，不影响判定。

## 四、两个臂
| 编号 | 学习率 | 批量 | 步数 | 其余 |
|---|---:|---:|---:|---|
| P37 | 1e-5 | 256 | 2000 | AdamW，weight_decay 0.01，betas (0.9, 0.999)，eps 1e-8，全新优化器状态；梯度范数裁剪 5.0（与训练配置相同） |
| P38 | 1e-4 | 256 | 2000 | 同上 |

两臂都从 P6@u256 重新加载开始（`load_actor(plan,'P6',256)`），互不继承。

**每一步：**
```python
g = torch.Generator().manual_seed(2026112601)          # 每个臂开头重新设定，两臂抽样序列相同
ids   = torch.randint(len(T), (256,), generator=g)
times = runtime.ddim_t[-runtime.ft_denoising_steps:].detach().cpu().long()   # 10 个
slots = torch.randint(len(times), (256,), generator=g)
noise = torch.randn((256,16,11), generator=g)
alpha = runtime.ddim_alphas[-len(times):][slots]
loss  = prefix_x0_loss(runtime, y[ids], cond[ids], W, times[slots], alpha, noise).mean()
```
- 与 `OnlineKeep.loss` 相同，只是批量为 256、目标为固定的 y。
- 条件 `cond[ids]` 用预先编码好的 `global_cond` 张量。
- W = `executed_weights('none')`。

**训练模式：**先在一个固定批上分别用 `train()` 与 `eval()` 算损失；两者逐位相同则用 `eval()`；不同就停下回报。

## 五、测量（第 0、250、500、…、2000 步，共 9 次）
对每个臂、每个测量点：
- U 上的确定性非引导输出 b_θ（X1 的 `pair`，种子 2026112400 + i，只取 b）；
- a = 均值‖b_θ − g_P6‖² / 均值‖Δ‖²，β = Σ⟨(b_θ − b_P6)·W, Δ⟩ / Σ(Δ²·W)，ρ = 均值‖b_θ − b_P6‖² / 均值‖Δ‖²。Δ = g_P6 − b_P6，‖x‖² = (x²·W).sum()/16，与 X1 相同；
- 训练集损失：T 的前 256 个状态，每个状态在 10 个时间步上各用一份固定噪声（生成器种子 2026112602），算十步平均损失；
- U 上的拟合损失：目标 g_P6，固定噪声（生成器种子 2026112603），十步平均；
- R 上的遗忘量：均值‖b_θ(R) − b_P6(R)‖²（若 R 可用）；
- 每个测量点存 b_θ(U) 原始张量。

训练过程每 50 步记录一次小批损失与裁剪前梯度范数。

## 六、核对（写入 `x2_checks.json`；任一不符即停）
1. 第 0 步 b_θ(U) 与 X1 的 `b['P6']` 逐位相同（两臂各核一次）。
2. T 与 U 的观测 SHA 交集为空（剔除后）；T 只来自 `records`。
3. 训练结束后，非 LoRA 参数与 P6 逐位相同；LoRA 参数已改变。
4. 确定性：P37 的前 10 步跑两次，10 步后 LoRA 参数逐位相同。
5. 第 0 步 a = 1、β = ρ = 0；每个测量点 |a − (1 − 2β + ρ)| < 1e-9。
6. 训练模式核对（第四节）。
