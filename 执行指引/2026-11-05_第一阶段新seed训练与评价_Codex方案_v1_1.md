## 一、目的

G16 表明：三次 F3@u256 运行相对 BC 的提升主要在第一阶段（u1—u128）形成，第二阶段平均没有增益。论文的核心贡献因此落在第一阶段后训练框架上。但第一阶段目前只有 P2 一次运行，三个 u256 运行都从它出发。本实验从 P0 用一个新 seed 按 P2 的配置重训第一阶段，回答一个问题：**第一阶段相对 BC 的提升能否在另一次独立运行上重现。**

## 二、处理臂与对照

| 臂 | 内容 | 父策略 | 预算 | 对照 |
|---|---|---|---|---|
| 新 seed@u128（编号由 Codex 按编号规范登记，运行前登记） | 第一阶段（F1）后训练，配置与 P2 的运行 `routea_common_b2560_seed202609203_v1` 逐行相同，只改 `run.seed` = **202611051** 与输出路径 | P0（BC） | 与 P2 相同：u1—u128，每轮转移数与优化器提交数取自 P2 配置 | 匹配对照 P0（同父、同评价）；同配置不同 seed 的 P2@u128 |

要求：
- **学习率调度与 P2 一致。** P2 是 `run.updates` = 256 的运行在 u128 处的检查点，新运行同样设 `updates` = 256，在 u128 停止。不能把 `updates` 改成 128，否则学习率调度不同。
- 不加保持项，不做第二阶段，不选检查点：只取 u128。
- 代码版本：优先使用能复现 P2 身份哈希的源码闭包。做不到时用当前闭包，在核对单中列出与 P2 训练时闭包的差别，按 G16 H11 的三类分法说明；论文写为"相同配置、后续代码版本"。

## 四、预先登记判据（写于运行之前）

统计（v1_1 改）：在 O′ 上计算新 seed@u128 相对 P0 的安全到达率差（O 上的结果在补充材料中作描述），用世界聚类 bootstrap 95% 区间（20000 次，seed 2026102601，与 G3/G16 相同）。以下界限是工程阈值，不是统计显著性检验。

**R2（第一阶段提升的可重复性）：**
- 区间下界 > 0：**符合采纳标准**。写"第一阶段后训练相对 BC 的提升在两次独立运行上均成立"，同时报告 P2 与新 seed 两个数值。
- 差为正、区间含 0：**不确定**。写"提升在 1/2 次运行上成立"，报告两个数值。
- 差 ≤ 0：**本预算下不符合采纳标准**。论文如实写明第一阶段提升未在第二次运行上重现；不推广为"方法无效"。

**描述项（不作判据）：**

- 按稀疏、适中、密集三类给出到达、碰撞、超时，并检查超时是否同样集中在距目标 2 m 内。
