## 命令（WSL）
```bash
R=/home/cjj/AUV/program/results/paper_186_v1_0_run01
O=/home/cjj/AUV/program/jindu/C侧_20261120_paper186_export
mkdir -p "$O"
# 1. 目录结构与各 traces 目录文件数
find "$R" -maxdepth 4 -type d | sort > "$O/tree.txt"
find "$R" -type d -name traces | sort > "$O/trace_dirs.txt"
for d in $(cat "$O/trace_dirs.txt"); do echo "$d $(ls "$d" | wc -l)"; done > "$O/trace_counts.txt"
# 2. 各 traces 目录第一个文件的首行前 3000 字节（用于确认方法身份）
for d in $(cat "$O/trace_dirs.txt"); do f=$(ls -d "$d"/* | head -1); echo "== $f"; head -c 3000 "$f"; echo; done > "$O/trace_heads.txt"
# 3. 除 EGO（已交）外全部原迹打包
cd "$R" && tar -czf "$O/paper186_traces_non_ego.tar.gz" --exclude='./ego' $(cd "$R" && find . -type d -name traces | grep -v '^./ego/' | sort)
# 4. 哈希与退出码
sha256sum "$O"/* > "$O/SHA256SUMS"; echo "rc=$?" >> "$O/commands_rc.log"
ls -la "$O"
```
第 3 步用到 `grep -v`，只用于从目录清单里去掉 EGO，不读写任何数据。若执行端不允许使用 `grep`，改为人工从 `trace_dirs.txt` 中挑出非 EGO 目录，逐个写进 `tar` 的参数。
