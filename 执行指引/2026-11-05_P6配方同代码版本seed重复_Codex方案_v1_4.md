## 一、要回答的问题

P6 是本文主要成果，但它是一次训练运行。论文线中与第二阶段有关的证据只有以下几条：
- P6（从 u128 分叉、有保持项）与 P4（从 u128 分叉、无保持项）在训练外世界上到达数接近（289 对 273），失败形态不同；
- P3（同一运行不中断训到 u256）在 dev420 #E1 下由 160 降到 129，即不中断的继续训练出现了退化；
- 同一 P6 运行在 u192 的 dev420 到达比 u256 少 40 次，说明结果对训练长度敏感。

审稿人会问：P6 配方重新训练一次，能否得到相近的结果。本实验在 P6 的同一代码版本（A2 源码闭包）下，用 P6 的配方换一个 seed 再训练一次，给出第二阶段的运行间差异。

## 四、预先登记判据（写于运行之前）

记 O′ 上的回合数为 n，本运行、P2、P6、P0 的到达数分别为 N、N₂、N₆、N₀（N₂、N₆、N₀ 由任务C 第 9 步得到）。统计口径与 G3、C5 相同：世界聚类 bootstrap，20000 次，seed 2026102601。下列界限是工程阈值，不是统计显著性检验。界限取 P6 相对 P2 增益的一半，即 N − N₂ ≥ (N₆ − N₂)/2。若 O′ 上 N₆ ≤ N₂，则 R3 无法按此界限判定，报告后由用户决定写法。

**R3（第二阶段提升的重复性）。** P6 在任何情况下都是本文主要成果，以下只决定消融段落与表注的写法。

| 结果 | 判定 | 论文写法 |
|---|---|---|
| N − N₂ ≥ (N₆ − N₂)/2，且 N − N₀ 的区间下界 > 0 | **符合采纳标准** | "按同一配方训练的两次运行都高于第一阶段"，报告 P6 与本运行的数值和两者的均值 |
| 0 < N − N₂ < (N₆ − N₂)/2 | **不确定** | "第二次运行高于第一阶段，但幅度小于 P6"，报告两次数值；讨论中写明第二阶段的提升幅度存在运行间差异 |
| N − N₂ ≥ (N₆ − N₂)/2，但 N − N₀ 的区间下界 ≤ 0 | **不确定** | "第二次运行相对第一阶段的提升达到本文方法的一半，但相对 BC 策略的提升区间含 0"，报告两次数值与区间 |
| N ≤ N₂ | **本预算下不符合采纳标准** | "第二阶段的提升未在第二次运行中重复"，报告两次数值，写入局限；第一阶段的提升仍由 P2 与 G17 支撑 |

O 上（540 回合）的同一比较作为描述项在补充材料中报告；原 v1_2 的固定界限 275 不再使用。判定只在扩展集 v2 冻结、经 Claude 复核、各策略补评完成之后进行，不能以 O 代判。

**写作中的披露：** 第二次运行与本文方法共享父策略、配置与数值计算代码，随机种子不同；分叉时按本文方法的方式恢复父运行的随机状态，因此两次运行的随机性只在回合重置与逐轮采样上不同，不是完全独立的重复。

**保持项比较（重新登记，取代原 G16 方案中的 C3b）：** F3 = {P6, 本运行}，F2 = {P3, P4}，均在 O′ 上计算。
- F3 均值 > F2 均值，且 F3 最小值 > F2 最大值：写"两次带保持项的运行都高于两次不带保持项的运行"；
- 只满足均值条件：写"带保持项的运行平均高于不带保持项的运行，但范围重叠"；
- 均值条件不满足：写"保持项对到达率的影响没有超出运行间差异"，保持项只报告其对路径效率与失败形态的影响。
- P3 与 P4 同 seed，F2 的极差会低估跨 seed 差异，表注写明。

**描述项（不作判据）：**
- 按稀疏、适中、密集三类给出到达、碰撞、超时；
- 路径效率中位数（检查 P6 对 P4 的路径效率差别是否在本运行上重现）；
- 本运行 − P6 的配对差，作为同配方的运行间差异。

**写作约定：** 无论结果如何，本运行都进入论文消融段落与表注，不因结果不利而删除。
