# 数字台账重建说明

按正文与补充材料中的每次数值出现位置登记，不按表格行或参数组压缩为一条。正文依据固定为上级 paper_commit.txt 的提交；本脚本不改稿件、不运行训练或评价。

- 数字台账.csv：原文片段、位置、独立数值、工作簿单元格或分析字段，外加源文件SHA及代码核对位置。百分比依原表比例乘100并保留稿件显示精度；保持比例按字段分子与固定任务分母重算。
- 无来源数字.csv：既包括尚不能唯一定位的数字，也包括已找到稿表来源但代码审查指出不一致或运行事实缺口的数字。不能把工作簿与稿件一致当作源代码或实际运行已经证实；具体原因在核对说明、代码核对结论列。
- 展示公式保留回报系数、风险距离、平均因子及clip范围，排除纯求和索引、范数阶数、公式序号和代数恒等式里的0/1。正文中的分布/方程标签、引用、world编号不作为实验数字。参数科学计数法是单个数值，不拆成底数和指数。
- 本台账是可追踪的工程草稿；未来源化的项目完整保留，不作估填或能力判断。最终数量及源稿SHA见 build_summary.json。部分仍需WSL已完成报告/日志或注册BC原始配置补足，不能标记为“所有数字已核实”。

重建命令（Windows工作区）：

```powershell
$env:PYTHONIOENCODING='utf-8'
python program/paper_wsl_20261109/scripts/rebuild_numeric_ledger.py
```

## 状态变更
